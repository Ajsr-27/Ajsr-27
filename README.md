## 🐱 Proyecto destacado: Neko Store

Una tienda online completa hecha con React, con catálogo de productos, carrito de compras y un panel de administración.

**✨ Características**
- 🛍️ Catálogo de productos y carrito de compras (Context API)
- 🔐 Autenticación con roles: administrador y usuario común
- 🧰 Panel de admin para gestionar productos (CRUD completo) y cupones de descuento
- 🖼️ Subida de imágenes con Imgbb
- 📱 Diseño responsive con menú hamburguesa
- 🎨 Paleta cálida marrón/beige con variables CSS de Tailwind v4

**🧱 Tecnologías:** `React` · `Vite` · `Tailwind CSS v4` · `React Router` · `Firebase (Firestore + Auth)` · `Imgbb` · `Vercel`
